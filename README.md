# JTorrent

> A browser-based torrent downloader for desktop, Android, and iOS.

[![Website](https://img.shields.io/badge/Website-jtorrent.in-6c5ce7?style=flat-square)](https://jtorrent.in/)
[![Status](https://img.shields.io/badge/Status-Early%20Beta-orange?style=flat-square)](https://jtorrent.in/)

JTorrent lets you access torrent downloads directly through your browser from a phone, tablet, laptop, or desktop.

No separate torrent client is required.

## Try JTorrent

Visit the website:

**[https://jtorrent.in/](https://jtorrent.in/)**

JTorrent is currently available in early beta.

## Features

- Works through a browser on desktop and mobile devices.
- Compatible with Windows, macOS, Linux, Android, iPhone, and iPad browsers.
- Magnet link support.
- `.torrent` file upload support.
- Individual file selection from collections.
- Complete collection downloads.
- Supported media previews with Pro and Premium plans.
- Free plan available for testing.

## Why JTorrent?

Installing and configuring a torrent client is not always convenient.

You may be using:

- A phone or tablet.
- A temporary laptop.
- A computer where software installation is restricted.
- A device that is not your primary machine.
- A browser-only environment.

JTorrent provides a simple way to access the workflow from different devices without installing a separate application.

## Mobile support

JTorrent is designed to work through mobile browsers, including:

- Safari on iPhone and iPad.
- Chrome and other supported browsers on Android.
- Desktop browsers on Windows, macOS, and Linux.

The mobile experience is still being improved during the beta period. Feedback about iOS, Android, file selection, and browser usability is welcome.

## Feedback and issues

If you find a problem, please open an issue with:

- Device and operating system.
- Browser name and version.
- Approximate file size.
- Whether you used a magnet link or `.torrent` file.
- The point where the problem occurred.
- A screenshot, if possible.

Please do not include private account information, copyrighted filenames, personal data, magnet links, or sensitive URLs in public issues.

## Security

Do not report security vulnerabilities through public GitHub issues.

For security-related concerns, contact the project owner privately through the contact method provided on the website.
